# 🌳 의사결정 트리(Decsion Tree)

## 정의

- 분류 및 회귀 작업에 사용되는 비모수 지도 학습 알고리즘
- 알고리즘의 트리를 이용해서 모델링을 해서 데이터를 분류하는 모델

## 활용 분야

- 수치 데이터에 대해서 트리 기반의 앙상블 모델 사용
- 시각화가 가능하여 신뢰와 설명이 필요한 분야에서 사용

## 개념

### 엔트로피

- 정의: 평균 정보량. 정보가 가지는 불확실성의 평균을 의미한다.
  - 불확실성 ⬆ -> 예측이 어려움(확률이 낮음) -> 유용한 정보를 가짐 -> 가지고 있는 정보의 양이 많음 -> 엔트로피⬆
  - 불확실성 ⬇ -> 예측이 쉬움(확률이 높음) -> 유용한 정보보다는 당연한 정보를 가짐 -> 가지고 있는 정보의 양이 적음 -> 엔트로피⬇
- 공식
  $$H(X) = -\sum_{i=1}^{n} P(x_i) \log_2 P(x_i)$$
  💡 정리 포인트
- 불확실성 ⬆ → 엔트로피 ⬆: (예: 내일 해가 서쪽에서 뜰 확률 - 매우 놀라운 정보)

- 불확실성 ⬇ → 엔트로피 ⬇: (예: 내일 해가 동쪽에서 뜰 확률 - 당연해서 정보가 안 됨)

- 불확실성이 낮은 모델이 되면 새로운 데이터에 대해서도 판단하는데 자신을 가지고 모호함을 가지지 않음(분류를 잘 함).

### GINI 계수

- 정의: 가지고 있는 데이터의 불순도를 나타내는 수치
  - 모든 클래스의 데이터를 균등하게 가지고 있다면 불순도가 높음을 의미하고, 이때 GINI 계수가 최대(GINI=0.5)가 된다.
  - 모든 데이터가 하나의 클래스를 가지면 불순도가 낮은 순수한 상태를 의미하고, 이때 GINI 계수가 최소(GINI=0)가 된다.
- 공식
  $$GINI(t) = 1 - \sum_{j}[p(j|t)]^2$$

### 정보 획득

- 정의: 질문을 던지기 전과 후의 엔트로피 차이
  - 분할 후 평균 엔트로피가 낮으면 질문을 던졌더니 데이터가 순수하게 잘 나뉘었다는 것을 의미 -> 정보 이득이 크다 -> 불확실성을 그만큼 많이 제거함을 의미
- 공식
  $$Information \space GAIN = (전체 엔트로피) - (분할 후 평균 엔트로피)$$
  $$Information \space GAIN = Entropy(p) - \sum_{i=1}^{k}\frac{n_i}{n}Entropy(i)$$

## 장단점

### 장점

- **많고 단순한 데이터에 대해서 성능이 좋음**. 트리의 깊이가 커지는 경우에는 과적합이 될 가능성이 있지만 단순한 데이터에 경우에는 트리의 깊이가 작기 때문에 과적합 가능성이 적으면서 좋은 모델이 될 수 있음.
- **데이터의 타입이 상관없음**. 다른 모델의 경우에는 입력이 숫자 형태여야 하지만 의사결정 트리는 데이터의 타입에 맞게 처리해주면 된다.
- **데티어 전처리에서의 유연성이 큼**. 다른 모델과 다르게 사전에 모든 데이터의 스케일링을 할 필요가 없으며, 데이터 간의 관계가 비선형이여도 상관없음.
- **쉽게 이해할 수 있음**. 모델을 보고 규칙을 쉽게 파악할 수 있어서 입력과 출력의 관계를 볼 수 있음.
- ### 단점
- **과적합이 발생하기 쉬움**. 데이터가 적거나 복잡하면 트리의 분할이 많아지고 트리의 깊이가 커져서 훈련 데이터에 대해서 잘 학습하게 되어서 과적합이 됨. 이때는 사전 가지치기나 사후 가지치기를 통해서 방지해야한다. 단, 항상 가지치기가 최고의 방법은 아님.
