# Project Proposal

## Decision Tree에서의 Cross Validation

---

# 1. Problem Statement(문제 정의)

본 연구는 교차 검증을 `sklearn` 라이브러를 사용하여, 의사결정 트리에서의 교차 검증의 유용성을 목표로 한다.

---

# 2. Motivation

- 교차 검증의 원리를 이해하고자함.
- 교차 검증이 유용한 지표인지 확인하고자 함.
- 교차 검증이 항상 최고의 평가 방법인가를 확인하고자 함.

---

# 3. Research Questions / Hypotesis (연구 질문 / 가설)

본 연구는 다음 가설을 검증한다:

1. 학습 전에 훈련용 데이터와 검증용 데이터로 분할하면서 모든 데이터를 학습에 활용할 수 없었지만 교차검증을 통해서 모든 데이터를 활용할 수 있어서 모델의 성능이 좋아질 것이다.
2. 트리 모델에서는 매번 새로 매개변수가 업데이트되므로 크게 성능 향상이 없을 것이다.

---

# 4. Methodology(방법론)

## 4.1 Algorithm Design(알고리즘 디자인)

- sklearn의 DecisionTreeClassifier를 사용하여 모델을 구성
- cross_val_score를 통해서 데이터를 훈련-검증 세트 k개로 구성하고, 학습하고 정확도를 산출

## 4.2 Experimental Setup(실험 준비)

- Dataset: Titanic
- fold of #: 5 / 10 (5는 계산 비용과 안정성 균형이 좋고, 10은 더 안정적인 추정)

## 4.3 Evaluation Metric(평가 지표)

- 정확도 평균

# 5. Expected Outcomes(예상 결과)

- 보통의 Epoch을 사용하여 데이터에 대해서 n회 학습하는 모델에서는 모든 데이터에 대해서 충분히 학습할 수 있어 성능이 더 잘 나올 것이다.
- 의사결정 트리는 데이터 전체를 1회만 사용하여 내부 매개변수를 업데이트하기 때문에 기존에 훈련-검증으로 나누어 학습했던 것과 성능 면에서 크게 차이가 없을 것이다.

# 6. Potential Limitations(잠재적인 한계)

- 기존의 경우에는 학습-검증을 한 번만 했다면 학습을 k번 반복해 학습 시간이 늘어난다.
