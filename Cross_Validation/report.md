# 2. Theoretical Background(이론적 배경)

## 2.1 Cross Validation

- 데이터를 k(하이퍼파라미터)의 부분집합으로 나눈다.
- k - 1개는 훈련용 데이터, 1개는 성능 측정용 데이터로 설정한다.
- 학습 후 성능을 구한다.
- 측정용 데이터가 겹치지 않게 하여 k번 학습을 한다.
- k개의 성능 지표의 평균을 구한다.

# 3.1 의사 코드

for i in range(1, k)

# 6. Limitations(한계)

- 데이터의 적은 경우 훈련와 검증 데이터가 전체 데이터의 특징을 가지고 있을 확률이 적기 때문에 학습 후 교차 검증을 사용하지 않은 모델은 한 번의 성능 측정으로 모델의 신뢰도를 판단해야 하지만, 교차 검증을 사용하면 여러 번의 교차 검증을 통해서 나온 성능 평가의 평균을 통해서 신뢰도를 판단할 수 있다. 하지만 이를 위해서 k번의 학습이 필요하므로 많은 자원 소모가 있다.
- 데이터의 양이 많은 경우 훈련와 검증 데이터가 전체 데이터의 특징을 가지고 있을 확률이 높기 때문에 검증을 통해서 검증을 여러 번 하지 않아도 검증을 통한 성능 평가에 대해서 신뢰할 수 있어서, 자원 소모라는 단점 때문에 큰 데이터에 대해서는 거의 사용하지 않는다.
