# 1. Introduction(소개)

## 1.1 Motivation(동기)

`Random Forest`는 여러 개의 `Decision Tree` 모델을 결합하여 분류 및 회귀 분석을 하는 모델이다.

# 2. Theoretical Background(이론적 배경)

## 2.1 Random Forest

- `Random Forest`는 샘플을 여러 번 뽑아 각 모델을 학습시키는 앙상블의 Bagging 모델 중 하나에 해당한다.
- `Decision Tree`를 여러 개를 사용하여 산출된 결과를 분류 경우에는 Majority Vote, 회귀 경우에는 Averaging을 이용해서 최종 결과를 생성한다.
- 여러 결과를 이용하여 때문에 하나의 이상한 결과에 영향이 적어 과적합에 빠질 위험이 감소하고 이로 인해 일반화 성능이 `Decision Tree`보다 좋다.
- 부트스트래핑을 통해 샘플링되지 않은 데이터를 통해서 성능을 측정하는 OOB가 있다.

## 2.2 Parallel Processing

- 병렬처리는 하나의 작업을 여러 개의 작은 작업으로 분할하여 동시에 처리하는 컴퓨팅 기술을 의미한다.
- 병렬처리에는 멀티 스레딩, 멀티 프로세싱
  - 멀티 스레딩
    - 정의: 프로세서의 스레드가 작업을 나눠서 작업을 처리하는 기술
    - 특징: 자원을 공유, 자원 접근은 하나의 스레드만 가능,프로세스보다 작은 단위인 스레드를 사용하기 때문에 생성 비용이 작음.
  - 멀티 프로세싱
    - 정의: 여러 개의 프로세서가 독립 태스크를 처리하는 기술
      - 특징: 독립적인 공간에 생성되어 자원을 공유하지 않음. 생성 비용이 비쌈.
- 파이썬의 경우에는 일반적인 상황에서는 프로세스 당 1개의 프로세스를 사용할 수 있기 때문에 스케줄링에 의해서 제대로 된 멀티 스레딩을 사용할 수 없다.

# 3. Implementation(구현)

- 트리들을 생성한다.
- 트리마다 부트스트래핑해서 학습을 한다.

## 3.2 병렬처리

- 각 트리의 학습을 독립 태스크로 분리하고 병렬로 처리한다.
